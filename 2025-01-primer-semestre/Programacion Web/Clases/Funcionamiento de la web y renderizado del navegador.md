## Renderizado del navegador
1. Carga de recursos 
2. Análisis del HTML (parsing), convierte el código HTML en un árbol DOM (Document Object Model), este árbol estructura el contenido jerárquicamente 
3. Procesamiento de CSS, descarga y analiza los archivos CSS. Crea el árbol de estilos (CSSOM, CSS Object) 
4. Construcción del árbol renderizado, combina el DOM y el CSSOM en un árbol de renderizado, que describe cómo se verá cada elemento 
5. Cálculo del Layout, determina las posiciones  
6. Pintado (painting) 
7.  Composición, renderiza elementos visuales, como animaciones o transiciones, en los niveles correctos,
