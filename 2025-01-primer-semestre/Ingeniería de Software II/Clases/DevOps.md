Plan, analiza los requerimientos - 
Code, los programadores empiezan a escribir el código 
Build, se junta todo el código y entrega un ejecutable
Test, se prueba para garantizar que funciona según los requerimientos
Release, todo listo para produccion
Deploy, poner en los servidores de prueba, ya ejecutarlo 
Operate, ocurre todo el tiempo son configuraciones, optimización 
Monitor, utiliza herramientas que siempre estan viendo la app a ver si falla o falla en un determinado momento (monitoreo)

CI/CD
CI (Integración continua), mezclar el código, pruebas automatizadas para cada vez que un programador agregue un código

CD Continues Distribution, crea un ejecutable para producción 

Herramientas para DevOps
- Planeación, Jira-Asana-Trello-Notion
- Código, GitHub-GitLab
- Build, Gradle-Apache Mave
- Test
- Release
- Deploy, jenkins
- Operate, chef-contenedores-micro servicios-docker-kubernetes
- Monitor, amazon cloud watch
