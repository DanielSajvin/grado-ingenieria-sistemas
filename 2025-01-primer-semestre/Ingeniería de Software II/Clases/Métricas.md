### Métricas del software 


En el software hay métricas para: 
- El producto (el software terminado)
- El proceso 
- El proyecto (es un plan de trabajo)

Indicador, es una métrica o combinación de métricas que proporcionan comprensión acerca del proceso del software o el producto en sí. 

¿Cuáles son los pasos?
- Determinar las mediciones y métricas del software que sean adecuadas de acuerdo a lo que se está construyendo 
- Recolectar los datos requeridos para las métricas formuladas 
- Ya calculadas, las métricas se analizan con base en lineamientos preestablecidos 
- Se interpretan los datos para obtener la información acerca de la calidad del software 

### Principios de medición
1. Formulación
2. Recolección 
3. Análisis 
4. Interpretación 
5. Realimentación

### Características fundamentales de las métricas del software 
- Consistentes en el empleo de unidades y tamaños 
- Realimentación de calidad
