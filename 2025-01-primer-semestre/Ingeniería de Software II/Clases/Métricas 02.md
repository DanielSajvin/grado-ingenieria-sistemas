Métricas de control, se asocian con procesos de software.
Métricas de predicción, se asocian con el software en sí.

Métricas de producto, son métricas de predicción usada para medir los atributos internos de un sistema de software.
Aunque las métricas de producto para el software son imperfectas pueden proporcionar una forma de valorar. 
Las métricas de producto se dividen en dos clases: 
1. Métricas dinámicas, se recopilan mediante mediciones hechas de un programa en ejecución  
2. Métricas estáticas, se recopilan cuando el software no está en funcionamiento o no está siendo utilizado 

Etapas clave en el proceso de medición de componentes: 
1. Elegir las mediciones a realizar 
2. Seleccionar componentes a valorar
3. Medir las características
