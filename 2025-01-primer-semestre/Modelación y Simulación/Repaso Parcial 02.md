## Diseño preliminar del experimento 
Se trata de definir qué variables son las entradas y cuáles las salidas, cómo va a modificarse el valor de las entradas y cómo van a recogerse los datos de salida. 

1. *Definición de objetivos del experimento:* especificar claramente qué  se espera lograr con la simulación.
2. *Selección de variables de entrada y salida:* 
	1. Variables de entrada, son los factores que se pueden ajustar en la simulación
	2. Variables de salida, son los resultados que se van a medir para evaluar el desempeño del sistema o el impacto de las variables de entrada.
3. *Diseño de escenarios de simulación:* se decide los diferentes escenarios que se probará durante la simulación. Cada escenario es una combinación específica de valores para las variables de entrada. 
4. *Configuración de parámetros del experimento:* se define cómo se llevará a cabo la simulación en términos de tiempo y repetición. 
5. *Métodos de recolección de datos:* define cómo se registrarán los resultados de la simulación y cómo se almacenarán para su análisis posterior. 
6. *Evaluación de recursos necesarios:* asegurarse de tener todos los recursos necesarios para realizar la simulación. 
7. *Pruebas de validación preliminares:* antes de ejecutar la simulación completa, realizar pruebas preliminares para verificar que todo esté configurado correctamente. Ejecutar la simulación con un escenario simple
8. *Documentación del diseño del experimento:* documentar todos los aspectos del diseño del experimento para asegurar que pueda ser replicado y comprendido por otros.

## Experimento 
Es el proceso de extraer datos de un sistema sobre el cual se ha ejercido una acción externa. Es decir, realizar todo en la vida real sin simulación, se hace una plan de lo que se quiere hacer y se ejecuta de una vez. 

# Preparación de los datos de entrada 

## 1. Recolección de datos 
Consiste en la obtención de todos los datos necesarios que se utilizarán en la simulación. Los datos pueden ser cuantitativos o cualitativos.

## 2. Limpieza de datos
Se enfoca en la identificación y corrección de errores, inconsistencias y valores atípicos en los datos. La limpieza incluye la eliminación de datos duplicados, la corrección de errores tipográficos y el manejo de datos faltantes. 

## 3. Filtrado de datos
Consiste en seleccionar solo los datos que son necesarios para la simulación. 

## 4. Transformación de datos
Adaptación de lo datos al formato requerido por el software de simulación. 

## 5. Estructuración de datos 
Organización de los datos en la estructura adecuada, como tablas, matrices o archivos específicos según lo necesite la herramienta de simulación. 

## 6. Generación de escenarios 
Creación de diferentes conjuntos de datos de entrada que representen distintos escenarios para la simulación. Esto permite explorar cómo diferentes condiciones afectan el sistema simulado. 

## 7. Verificación de datos
Verificación de que los datos preparados son correctos y están listos para ser utilizados en la simulación.
