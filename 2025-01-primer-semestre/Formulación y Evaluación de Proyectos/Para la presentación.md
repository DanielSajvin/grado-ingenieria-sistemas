## Necesidades y problemas actuales 
Las clínicas enfrentan desafíos como:
- Altas tasas de cancelación o ausentismo de pacientes, por falta de recordatorios.
- Pérdida de tiempo en la gestión manual de citas.
- Falta de una base de datos organizada de pacientes y sus historiales.
- Dificultad en la coordinación de horarios entre médicos.
## ¿Qué es TuCitaMed?
Es un sistema de gestión de turnos y citas médicas diseñado para clínicas y centros médicos pequeños o medianos. El sistema permite a los pacientes agendar sus citas desde una interfaz web o móvil, mientras que las clínicas pueden administrar fácilmente su calendario, reduciendo tiempos de espera y mejorando la experiencia del usuario. Este proyecto está orientado a centros médicos que desean digitalizar su gestión de citas sin incurrir en altos costos de implementación.

_Características principales:_
✓ Registro de pacientes y médicos.
✓ Agenda electrónica para la gestión de turnos.
✓ Envío de recordatorios automáticos por correo electrónico o WhatsApp.
✓ Reportes básicos (turnos atendidos, no asistencias, reprogramación de citas, pacientes atendidos al mes).
✓ Diseño responsivo para computadoras, tablets y teléfonos móviles.
✓ Historial médico, permite al paciente ingresar síntomas y quedan almacenados para que el médico los pueda ver.
