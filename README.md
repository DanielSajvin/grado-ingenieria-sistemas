## 🎯 Objetivo del Repositorio
* Este espacio no es solo un respaldo de archivos. Aquí documento mi evolución académica, desde mis inicios en 2021 hasta mi formación actual.
  
---

## 📂 Estructura del Archivo
El repositorio sigue una **arquitectura cronológica** estricta para asegurar que cada recurso sea localizable en segundos:

```text
📦 trayectoria-academica
 ┣ 📂 2021-01-primer-ciclo
 ┣ 📂 2021-02-interciclo
 ┣ 📂 2021-03-segundo-ciclo
 ┣ ...
 ┣ 📂 2026-01-primer-semestre (Actual 📍)
 ┗ 📜 README.md
```

Dentro de cada curso, la información se organiza por Unidades, conteniendo carpetas de Tareas, Clases, Repaso y Laboratorios.

---

> [!IMPORTANT]
> **Sobre la integridad de los recursos:**
> existen ciertos cursos que no cuentan con una carpeta dentro de este repositorio. Esto se debe a que la naturaleza de su desarrollo (clases puramente teóricas, exámenes presenciales sin entregables digitales o actividades en plataformas externas cerradas) no permitió recolectar archivos o recursos tangibles para ser subidos. Sin embargo, el conocimiento adquirido en ellos es pilar fundamental de mi formación académica.
