# Protocolo DNS
Es un sistema de nombres de dominio. Es como una agenda interna de internet. Es un sistema que traduce los nombres de dominio que los humanos entienden (www.sitio.com) a direcciones IP numéricas (como 172.217.160.142) que las computadoras necesitan para encontrarse y comunicarse en la red.
