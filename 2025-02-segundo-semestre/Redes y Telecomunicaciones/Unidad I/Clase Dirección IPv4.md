## IPv4
Un host necesita una dirección IPv4 para participar en internet y en casi todas las LAN hoy en día. La dirección IPv4 es una dirección de red lógica que identifica a un host en particular. 
Limitado a un número limitado de host. 

Las direcciones IPv4 tiene 32 bits (1bit - 4 bytes) de longitud

Divisiones para sub-redes y lo restante será para host (usuarios finales)
