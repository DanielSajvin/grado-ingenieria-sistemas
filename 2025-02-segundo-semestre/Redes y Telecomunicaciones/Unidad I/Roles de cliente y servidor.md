ISP, proveedor de internet 

Los hosts pueden enviar y recibir mensajes a través de la red.

## Servidores
_Correo electrónico_, ejecuta el software de correo electrónico. 
_Web_, el servidor web ejecuta software de servidor web. Los clientes usan un software de navegador, como Windows Internet Explorer, para acceder de páginas web en el servidor 
_Archivo_, almacena archivos de usuario y empresariales en una ubicación central. 

## Redes entre pares (Peer-to-Peer P2P)
Una aplicación permite que un dispositivo funcione, como cliente y servidor dentro de la misma comunicación. En este modelo, cada cliente es un servidor y cada servidor es un cliente. Requieren que cada terminal proporcione una interfaz de usuario y ejecute un servicio en segundo plano. 

# Múltiples roles en la red

## Infraestructura de red
Contiene 3 categorías de componentes de hardware:
1. Dispositivos finales (host-cliente)
2. Dispositivos intermedios
3. Medios de red

## Servicios del ISP
Constituye el eslabón entre la red doméstica y la internet. 

_Conexiones_ la interconexión de los ISP que conforman la red troncal de internet es una red compleja de cables de fibra óptica con conmutadores y enrutadores de red. 

## Conexiones de Cables y DSL

### Cable
Es un servicio ofrecido por proveedores de servicios de televisión por cable. La seña de datos de internet se transmite a través del mismo cable coaxial que transporta la señal

### DSL
Línea de Suscriptor Digital, proporciona una conexión a internet siempre activa de un ancho de banda elevado.
