## MAC (tarjeta de interfaz de red)
En redes, MAC significa Media Access Control (Control de Acceso al Medio). Es un identificador único asignado a cada tarjeta o dispositivo de red (como una tarjeta Ethernet o Wi-Fi). Este identificador, también conocido como dirección física, permite que los dispositivos se comuniquen entre sí dentro de una red local.
Es un identificador único  asignado a una tarjeta de red NIC

## Conmutadores de Ethernet
Dispositivo de red que conecta múltiples dispositivos en una red local (LAN) usando cables Ethernet. 

## Tablas de direcciones MAC
Es una base de datos que los switches usa para mapear direcciones MAC de dispositivos a puertos específicos.
